**Status:** parked · **Verdict:** formation viable; mass conversion is the

  near-spherical fragmentation during radiation domination all fail —
  every model gives O(1–20) relics per progenitor vs the required
  10¹⁶–10³⁰. Only a horizon-destroying "shattering bounce" existing in
  no literature could work (requirements spec R1–R8 recorded).
