# Hercules–Corona Borealis Great Wall as a Gpc-scale matter overdensity

**Status:** killed (2026-10-03) · **Verdict:** ruled out

## What happened
The candidate (a ~50% GRB excess in the standard cap/slice) was tested
against 116,000 DESI DR1 quasars in the exact same cap and redshift
slice: δ = +1.6%, p = 0.22 vs 500 control caps. Reconciling the GRB
excess with the quasar null would require an unphysical GRB bias
b_GRB > 27.

## Record
Killed with prejudice. Revival would need new, independent data
contradicting the DESI null — not a re-analysis of the same data.

(Atlas, 2026-10-06)
